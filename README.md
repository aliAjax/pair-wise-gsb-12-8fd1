# 发电车调度台

暴雨应急抢修场景的发电车调度小工具，纯原生 ES Module 实现，**无运行时依赖**（仅开发期用 Vite 起本地服务）。

## 功能

- **车辆资料**：车牌、班组、可用时段、额定功率、余油/油箱容量、作业油耗
- **故障单**：地点、负荷、开始时刻、预计时长
- **调度判定**
  - 同一辆车避开已有任务（作业窗口不得重叠）
  - 可用时段要完整覆盖作业窗口
  - 额定功率 ≥ 负荷，余油 ≥ 油耗 × 时长（够整段作业）
  - 缺一项就停在「待分配」，并在卡片上注明缺口
- **状态流转**：待分配 → 已派车 → 到场（按整段时长扣燃油）→ 完工回场（释放车辆）；回场前任意环节可撤单，撤单立刻释放车辆
- **本地保存**：所有改动自动写入 localStorage，可一键恢复默认数据

## 目录

| 文件 | 职责 |
| --- | --- |
| `src/data.js` | 车辆资料：数据模型、常量、种子数据 |
| `src/dispatch.js` | 调度判定：纯函数，不碰页面和存储 |
| `src/storage.js` | 本地保存：localStorage 读写与回退 |
| `src/app.js` | 页面：渲染与交互 |
| `src/styles.css` | 样式 |

## 启动

```bash
npm install
npm run dev
```

构建：`npm run build`，预览：`npm run preview`。
